# mattykuch.github.io

Matt's personal portfolio site — a curated collection of data visualization projects, interactive dashboards, and data-driven stories spanning public health, education, agriculture, and sports.

**Live site:** [mattykuch.github.io](https://mattykuch.github.io)

## About

This is a static GitHub Pages site with no build step or package manager. Each project lives in its own subdirectory or is hosted externally, linked from the main gallery page.

### Featured Projects

- **Measles in Africa** — A data-driven exploration of measles across Africa
- **The Case for HPV Vaccine in PNG** — A data story for HPV vaccine introduction in Papua New Guinea
- **Bounce Back** — What makes NBA legends great, told through data
- **JC Farms Dashboard** — Decision-support dashboard for a farm operation
- **Modern House Building in Africa 101** — Visual guide with cost-saving tips from Uganda

### Archive

- UCE Performance Bumpchart
- UCE Failure Rate Profile by District
- Kampala District Population Distribution by Parish

## Tech Stack

- Vanilla HTML, CSS, and JavaScript
- D3.js for data visualizations
- Highcharts (select projects)
- GitHub Pages for hosting

## Local Development

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server
```
